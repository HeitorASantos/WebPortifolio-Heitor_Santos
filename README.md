I've been learning and programming since 2025, and I'm constantly trying to improve my skills by developing new applications, learning different programming languages, and challenging myself to step outside my comfort zone.

## 📌 About the Project

This is my personal web portfolio, developed by myself to showcase my projects, skills, and learning journey as a programmer.

The website is divided into five main sections:

*  `Home` — An introduction to the portfolio.
*  `About Me` — Information about myself and my background.
*  `Projects` — A collection of projects I have developed.
*  `Knowledge` — Technologies, programming languages, and skills I have learned over time.
*  `Contact` — My social media and contact information.

The portfolio itself is also one of my projects. I've been working on it since 2025, continuously improving its design, structure, and functionality as I learn new technologies.
